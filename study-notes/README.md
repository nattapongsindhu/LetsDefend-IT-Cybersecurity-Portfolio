## How I take notes

For each topic I write three things:

1. **The idea in one paragraph.** If I cannot explain it in a paragraph, I do not understand it yet.
2. **What it looks like in evidence.** Which log, which field, which artefact shows this happening.
3. **Where I got it wrong.** My first attempts usually miss something; writing down the miss is what
   makes it stick.

The third part is the reason these notes exist. A summary of a course is not knowledge; a record of my
own mistakes is.
